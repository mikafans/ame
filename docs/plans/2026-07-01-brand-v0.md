# Brand v0 — implementation plan (2026-07-01)

Locks the `ame` visual identity as **version 0** and wires it into the app. The design
exploration is done and signed off; this doc is the build plan. Durable task state lives
in the asobi epic **`ame:brand-v0`** (`/asobi tasks list ame:brand-v0`) — this file is the
human-readable mirror.

## Decision (locked)

- **Mascot = a chibi Hatsune Miku** (actual likeness), Fuwa-plush proportions: big round
  head, twin-tails, small seated body, teal tie. Blushy dot-smile face. **Animated** —
  twin-tail sway + slow bob + occasional blink; freezes under `prefers-reduced-motion`.
- Shipped as **two theme sets** (light + dark), each a self-contained animated SVG.
- Assets: `design/preview/miku-icon-light.svg`, `design/preview/miku-icon-dark.svg`.
  Canonical preview board: `design/preview/mascot-final.html`.

> **Reverses** the [refresh-and-rebrand plan](2026-07-01-refresh-and-rebrand.md)'s
> "palette + motif only, no Miku likeness" line (which existed for Crypton licensing).
> Likeness was chosen knowingly — fine for fan/personal use; **flag before any commercial
> shipped-brand use.**

## Tasks (mirror of asobi `ame:brand-v0`)

1. **task-1 — Brand assets + theme-aware favicon.** Copy both SVGs to `web/public/`; wire
   `metadata.icons` in `web/app/layout.tsx` with a `prefers-color-scheme` dark variant;
   add a static 16px fallback.
2. **task-2 — ThemeRegistry palette swap.** `web/src/components/ThemeRegistry.tsx`
   `buildTheme()` palette block (~L33–54): indigo→teal, emerald→pink, backgrounds per
   table. Verify AA contrast **before** commit.
3. **task-3 — Wordmark + mascot in Topbar.** `web/src/components/Topbar.tsx`: lowercase
   `ame` teal→pink gradient wordmark + the theme-aware animated mascot (~28–34px).
4. **task-4 — Tagline + metadata.** "ame — study, sweetened" into `web/app/layout.tsx`
   metadata, `README.md`, and the `skill.json` description (`api/src/http/mod.rs` +
   `docs/public/llms.txt`).
5. **task-5 — e2e/visual smoke** *(blocked on task-3)*. `web/e2e/`: theme toggle applies
   the palette + swaps favicon/mascot; reduce-motion freezes the animation. Tests ship in
   the epic (retro rule #2), not offloaded to manual check.

## Kill-gate / scope guard

IN: palette, favicon, wordmark+mascot, tagline. **OUT** (→ v0.5 retention epic): candy-jar
streak, XP-as-"sugar", SRS, any new learner surface. No Tailwind, no per-page restyling.
