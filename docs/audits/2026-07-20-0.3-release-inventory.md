## Evidence boundary

The clean release gate used an isolated compose project and disposable named
volumes; the normal local-stack volumes were not removed. The public files were
served directly by containerized Caddy from `docs/public`, while `/public/v1/*`
continued to reverse-proxy to the API.

## Consistency verification

`make check` passed with 65 Rust tests, 24 frontend tests, OpenAPI snapshot
parity, and generated frontend schema parity. The isolated release rehearsal
also passed `make local-uiux` with four browser behavior tests. The first
rehearsal run correctly exposed that the returning-learner fixture expected the
canonical demo prompt; the clean seed then added that prompt alongside Haru's
Flink journey and the full browser gate passed.
