## Evidence boundary

The current green gates prove the implementation on the existing local named
volumes. They do not yet prove a fresh-volume release. No migration or volume
destruction is implied by this inventory; the clean-volume rehearsal must use an
isolated compose project or an explicitly disposable environment.
