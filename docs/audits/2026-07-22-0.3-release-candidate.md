## R4 — Restart and resume persistence

Result: PASS on the isolated `ame-clean` project.

The enhanced `scripts/test_local_stack_persistence.py` registered a fresh
learner, created a prompt-grounded journey, read the recommendation through
both the journey and progress endpoints, started an in-progress activity
session, then ran the documented non-destructive `down`/`up` restart. After
re-login it verified:

- the same journey ID and exact raw intent;
- the same recommendation activity/objective/evidence identifiers;
- the same in-progress session ID, journey ID, activity ID, and status through
  `GET /api/v1/learning/sessions/{id}`.
